# Navnit Pandey Portfolio

A dependency-free, responsive one-page portfolio/CV website based on the supplied résumé.

## Open it

Open `index.html` in any modern web browser. No build or installation step is required.

## Personalise it later

- Add project cards in the `#focus` section as work becomes available.
- Replace the monogram with a headshot if desired.
- Update the contact links and education information directly in `index.html`.

The site supports keyboard navigation, reduced-motion settings, mobile navigation, and printing.
